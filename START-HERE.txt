TEACH FEES TRACKER — FIREBASE LOGIN + SYNC

1) In Firebase Authentication enable BOTH:
   - Email/Password
   - Anonymous

2) In Firestore > Rules, paste the included firestore.rules and Publish.

3) Copy .env.example to a new file named .env and paste your Firebase Web App values.

4) In this folder run:
   npm install
   npm run dev

5) First time: Create account with Name + Date of Birth + Viewer Code.
   Next device: Sign in with the SAME Name + Date of Birth.

6) To publish:
   npm run build
   firebase deploy --only hosting

IMPORTANT:
Date of birth is being used as the account secret because this is the simple login requested. It is not as strong as a real password. Keep the viewer code at 6 digits and do not use this app for highly sensitive information.
